# ADR Property Management: landing page concept

A single-page design concept for ADR Property Management: apartments, self storage and retail space.

Open `index.html` in a browser. No build step or dependencies; fonts load from Google Fonts and photos from Unsplash.

## What's in it

- Search across apartments, storage and retail
- Listings with availability and up-front pricing
- Storage site plan: pick an exact unit, add it to a cart, reserve it
- Customer portal preview with request tracking
- Guarantees, reviews, application criteria and FAQ, owners section
- Responsive from 320px phones to desktop, with click and scroll effects (reduced for users who prefer less motion)

Listings, prices, reviews and figures are sample content.
